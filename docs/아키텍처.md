# 아키텍처

## 클라이언트 (Flutter)

```
lib/
├── main.dart                        # 엔트리, 테마, Provider, AuthGate
└── src/
    ├── config/app_keys.dart         # 카카오/네이버 키 (플레이스홀더)
    ├── models/                      # NowPlaying, Friend, AppUser
    ├── services/
    │   ├── auth_service.dart        # 카카오/네이버/이메일 로그인 + 세션
    │   ├── spotify_auth.dart        # OAuth PKCE + 토큰 갱신
    │   ├── spotify_api.dart         # currently-playing / recently-played
    │   ├── media_session_channel.dart  # Android 네이티브 채널
    │   ├── now_playing_service.dart # 소스 통합 (네이티브 > Spotify)
    │   └── contacts_service.dart    # 연락처 + 번호 정규화(E.164)
    ├── repositories/friends_repository.dart  # 목업 → 백엔드 교체 지점
    ├── screens/                     # 로그인/가입/홈/친구찾기/설정
    └── widgets/
```

## 핵심 기술 결정

| 결정 | 이유 |
|---|---|
| 국내 스트리밍은 Android MediaSession으로 감지 | 멜론/지니/FLO 공개 API 없음 → [[조사/스트리밍 API 현황]] |
| iOS는 Spotify(+추후 Apple Music)만 | iOS 샌드박스가 타 앱 재생 정보 차단 |
| `FriendsRepository` 인터페이스 분리 | 백엔드 도입 시 목업만 교체 |
| 이메일 가입 로컬 목업 | 백엔드 전 단계, `AuthService`에 교체 지점 주석 |
| 연락처 매칭은 번호 해시 전송 예정 | 원본 번호 서버 저장 회피 (개인정보) |
