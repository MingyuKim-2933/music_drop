## Play Console 절차 (https://play.google.com/console)

### 1. 앱 만들기
- [ ] `앱 만들기` → 이름 **MUSE**, 기본 언어 **한국어**, 앱(게임 아님), 무료
- [ ] 선언 체크박스 동의

### 2. 앱 설정 (대시보드 "앱 설정" 섹션 순서대로)
- [ ] **개인정보처리방침**: 위 URL 입력
- [ ] **앱 액세스 권한**: "전체 기능이 특별한 액세스 없이 사용 가능" 아님 → 로그인 필요 앱이므로 **테스트 계정 제공**: `appuser.sb.test@gmail.com` / `test1234!`
- [ ] **광고**: 광고 없음
- [ ] **콘텐츠 등급**: 설문 → 소셜/커뮤니케이션 → 전체이용가 예상
- [ ] **타겟층**: 만 13세 이상 권장 (연락처/소셜 기능)
- [ ] **뉴스 앱**: 아니요
- [ ] **데이터 보안**: 아래 표대로 신고

| 데이터 | 수집 | 공유 | 암호화 | 삭제 요청 |
|---|---|---|---|---|
| 이메일, 이름(닉네임) | ✅ | ❌ | ✅ 전송 중 암호화 | ✅ |
| 전화번호(해시) | ✅ 선택 | ❌ | ✅ | ✅ |
| 연락처 | 기기에서 조회만, 해시 매칭용 전송(저장 안 함) | ❌ | ✅ | - |
| 앱 활동(감상 곡 정보, 플레이리스트) | ✅ | ❌ | ✅ | ✅ |

### 3. 스토어 등록정보
- [ ] 앱 이름: **MUSE**
- [ ] 간단한 설명(80자):
  > 친구들이 지금 듣는 음악을 실시간으로 — 멜론·스포티파이·유튜브뮤직 함께 쓰는 소셜 뮤직
- [ ] 자세한 설명: 아래 초안 사용
- [ ] 앱 아이콘: `icon_512.png` / 피처 그래픽: `feature_graphic.png` / 스크린샷: `assets/store/` 5장

### 4. 테스트 트랙 → 출시
- [ ] **내부 테스트** 트랙 생성 → `app-release.aab` 업로드 → 본인 이메일을 테스터로 등록 → 폰에서 설치 확인
- [ ] 문제 없으면 **프로덕션** 트랙으로 출시 → 심사 (보통 수일)

> 참고: 신규 개인 개발자 계정은 프로덕션 전 **20명 테스터로 14일 비공개 테스트** 요건이 있을 수 있음.
> 콘솔 안내에 따라 진행 (내부 테스트 → 비공개 테스트 → 프로덕션).

## 자세한 설명 초안

```
🎧 MUSE — 친구들이 지금 듣는 음악, 실시간으로 함께

지금 이 순간 친구가 무슨 노래를 듣고 있는지 궁금하지 않나요?
MUSE는 멜론, 지니뮤직, FLO, 유튜브뮤직, 스포티파이 — 어떤 앱으로 듣든
친구들과 실시간으로 음악을 공유하는 소셜 뮤직 앱입니다.

주요 기능
• 지금 듣는 중 — 내가 재생하는 곡이 친구 피드에 실시간 표시
• 친구 피드 — 친구들이 듣는 곡을 한눈에, 이모지 반응으로 공감
• 플레이리스트 — 곡을 검색해 나만의 리스트를 만들고, 친구 것을 퍼오기
• 연락처 친구 찾기 — 전화번호는 암호화(해시)되어 안전하게 매칭
• 실시간 알림 — 친구가 내 음악에 반응하면 바로 알림

개인정보 보호
• 음원 파일은 수집하지 않으며 곡 제목·아티스트 정보만 사용합니다
• 전화번호는 원본이 아닌 암호화된 해시만 저장됩니다
```
